## Responsive Behavior

### Desktop (> 1024px)
- Full sidebar with text labels
- Icons + text visible
- Collapsible to icon-only mode

### Tablet (768px - 1024px)
- Collapsible sidebar
- Overlay mode available
- Icons + text when expanded

### Mobile (< 768px)
- Drawer/overlay sidebar
- Swipe to open/close
- Full-screen when open
- Icons + text visible

## Implementation Notes

1. **Dynamic Loading**: Sidebar items load based on authenticated user's role
2. **Real-time Updates**: Navigation updates immediately when role changes
3. **Permission Checks**: Backend validates all route access attempts
4. **Graceful Degradation**: Falls back to minimal navigation if role is undefined
5. **Accessibility**: Full keyboard navigation and screen reader support
